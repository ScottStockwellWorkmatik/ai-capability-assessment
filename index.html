        The five levels

        How the scores work

        1. Capability score. The level you choose, 1 to 5.
        2. Category score. The average of the scored capabilities in that category. Out-of-scope capabilities are left out.
        3. Overall score. The average of the seven category scores, so every category carries equal weight. The level name is the nearest whole level.
        4. Critical capabilities. Four starred capabilities (S1, S3, S4, W2) are flagged if they score at or below the threshold, whatever the average says.
        5. Uneven profile. Flagged when the strongest and weakest category differ by the threshold or more, because practices reinforce one another and the weakest area holds back value.

        Save, continue or revisit an assessment

        1. Save your work. On the Results tab, select Download results (XLSX). You can download at any point, including a part-finished assessment, and unscored capabilities are simply left blank.
        2. Come back later. Open this page, stay on the Assessment tab and select Load a saved assessment (XLSX). Choose the file you downloaded.
        3. Check the message. A green line under the buttons confirms how many scores were loaded. Scored capabilities, evidence notes, out-of-scope marks, the organisation, assessor, date and both thresholds all come back.
        4. Carry on. Score the remaining capabilities or change earlier ones, then download again. Use a new file name, or a new date, if you want to keep the earlier version as a historic record.

        Good to know: loading a file replaces whatever is on the page, so download first if you have unsaved scores. Only files downloaded from this tool will load. Keep the Scoring sheet and its column headings as they are. You can edit scores or notes in Excel before loading, as long as scores stay between 1 and 5. The page keeps nothing between visits, so the file is your only record. To see progress between assessments, use the Compare tab.

        Compare progress over time

        1. Gather your files. Use the XLSX files downloaded from this tool, one per assessment. Each needs an assessment date in the Summary sheet (the app fills this in when you download). Up to six earlier files can be compared.
        2. Open the Compare tab. Select Add earlier assessments (XLSX) and choose one or several files at once. A green line confirms each one added.
        3. Include today’s work if you want. Tick Include the assessment currently on the Assessment tab to put your current scores last in the sequence. Untick it to compare saved files only.
        4. Read the results. Assessments are ordered by date. You get the overall trend, each category side by side with the change from first to last, a radar chart with every assessment overlaid, the four critical capabilities over time, and the capabilities that improved or declined.
        5. Save the comparison. Select Download comparison (XLSX) for a workbook with the tables and the overlaid radar chart.

        The comparison uses only the capabilities scored in both the first and the last assessment when it counts improvements and declines. Change in a category is shown even if different capabilities were scored, so check the “Scored” column in the first table when a score looks surprising. The critical-gap flag uses the threshold on the Results tab.

        About the evidence

        Each capability carries an evidence level. Survey-tested means the practice was tested in a McKinsey Global Survey and linked to higher performers. Framework-supported means a published framework or commentary supports it. Proposed means it is the author’s judgement with no direct source. Open Source and evidence under any capability to see the basis.

        The level descriptors, critical flags, thresholds and journey-map phases are the author’s draft judgement and have no published source.

        Link to your workflows

        If you have scored workflows in the AI Workflow Assessment, load its Excel file at the bottom of the Assessment tab. The page lists the capabilities those workflows depend on, which workflows flag them, and how you scored them here. The download then includes a Workflow links sheet. The links follow simple rules (for example low repeatability points to W1) and are the author’s judgement.

        About your data

        This page has no server, no account and no tracking. Scores exist only in this browser tab and are lost when you close or refresh it, unless you download the XLSX. Loaded files are read locally and never uploaded.
